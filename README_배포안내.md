# ICOLD 2027 설문조사 페이지 — 배포 안내

이 폴더(`site/`) 전체가 하나의 완결된 설문조사 웹앱입니다.
PHP가 실행되는 웹호스팅이라면 어디든 그대로 업로드해서 쓸 수 있습니다
(워드프레스가 돌아가는 호스팅은 기본적으로 PHP를 지원하므로 대부분 바로 사용 가능합니다).

별도의 데이터베이스 서버(MySQL 등)가 필요 없습니다. 응답 데이터는 `data/survey.sqlite`
라는 파일 하나에 저장됩니다 (PHP 기본 내장 SQLite 사용).

---

## 1. 왜 "PC를 꺼도 접속되는" 페이지가 되는가

이 파일들을 **호스팅업체 서버**(icold2027daejeon.com이 올라가 있는 그 서버)에 업로드하면,
그 순간부터는 김윤리님의 PC와 완전히 무관하게 호스팅사의 서버가 24시간 응답합니다.
반대로 말하면, 이 폴더를 내 PC에서만 실행하면 PC를 꺼는 순간 접속이 끊깁니다.
**반드시 호스팅사 서버(또는 FTP로 접근 가능한 실제 웹서버)에 올려야** 요청하신 조건이 충족됩니다.

## 2. 필요 환경 (호스팅업체에 문의할 내용)

- PHP 7.4 이상 (8.x면 더 좋음)
- PHP의 `pdo_sqlite` 확장 (대부분의 호스팅에 기본 활성화되어 있습니다)
- `.htaccess` 사용 가능 (Apache `mod_rewrite`/`mod_authz_core` — 대부분의 국내 호스팅 기본 지원)

호스팅업체(또는 홈페이지 제작사)에 아래처럼 요청하시면 됩니다:
> "icold2027daejeon.com 하위에 `/survey` 폴더를 만들고, 첨부하는 PHP 파일들을 업로드해 주세요.
> PHP 7.4 이상, pdo_sqlite 확장이 필요합니다. 업로드 후 `data` 폴더에 쓰기 권한(755 또는 775)을
> 설정해 주세요."

## 3. 업로드 방법

1. `site` 폴더 안의 **모든 파일과 폴더**(`.htaccess` 포함, 숨김 파일이라 안 보일 수 있으니 주의)를
   FTP로 웹호스팅의 `public_html`(또는 `www`, `htdocs`) 아래 **`survey`라는 새 폴더**를 만들어 그대로 업로드합니다.
   - 예: `public_html/survey/index.php`, `public_html/survey/images/q1-a.jpg` ...
2. 업로드 후 `survey/data` 폴더의 권한을 **755 또는 775**로 설정합니다 (웹서버가 그 안에 파일을 쓸 수 있어야
   응답이 저장됩니다). FTP 클라이언트(파일질라 등)에서 폴더 우클릭 → 파일 속성(권한)에서 변경 가능합니다.
3. 브라우저에서 `https://icold2027daejeon.com/survey/` 접속 → 설문 페이지가 뜨면 성공입니다.
4. 테스트로 설문에 응답 1건을 제출해 보고, `https://icold2027daejeon.com/survey/admin/` 에서
   방금 응답이 통계에 잡히는지 확인하세요.

## 5. 홈페이지 팝업 연동

`popup_snippet.html` 파일 안의 코드를 icold2027daejeon.com 홈페이지에 삽입하면,
방문자가 사이트에 처음 들어왔을 때 설문조사 팝업이 뜨고 "Take the Survey / 바로가기" 버튼을
누르면 설문 페이지(`/survey/`)로 이동합니다.

- 워드프레스라면: 외모(Appearance) → 테마 편집기 → `footer.php`의 `</body>` 태그 바로 위에
  붙여넣거나, "Insert Headers and Footers" 같은 플러그인 / 커스텀 HTML 위젯을 사용하면 됩니다.
- 직접 코드를 다루기 어려우시면 이 파일을 홈페이지 제작사(호스팅업체)에 그대로 전달하시면 됩니다.
- 팝업 안의 설문 URL(`https://icold2027daejeon.com/survey/`)은 실제 배포 경로와 다르면
  `popup_snippet.html` 안에서 직접 수정하시면 됩니다.

## 6. 폴더 구성

```
site/
  index.php          설문 메인 페이지 (영어/한국어 전환 가능)
  submit.php         응답 저장 처리
  db.php             SQLite 연결/스키마
  data_config.php     문항·보기·이미지 정의 (문항 문구 수정은 여기서)
  form_render.php     설문 화면 렌더링 로직
  admin_config.php    관리자 로그인 정보 (배포 후 비밀번호 변경 필수)
  style.css / images/ 디자인, 사진
  data/                응답이 저장되는 SQLite 파일 (자동 생성, 외부 접근 차단됨)
  admin/               통계 대시보드 + CSV 내보내기 (로그인 필요)
  popup_snippet.html   홈페이지에 붙여넣을 팝업 코드
```

## 7. 문항 수정이 필요할 때

문항 제목, 보기 문구(영/한), 사진 파일명은 모두 `data_config.php` 한 파일에 정리되어 있습니다.
문구만 바꾸고 싶다면 이 파일만 열어 텍스트를 수정한 뒤 다시 업로드하면 됩니다.
사진을 바꾸려면 `images/` 폴더에 같은 파일명으로 교체하거나, `data_config.php`의 `img` 값을
새 파일명으로 바꾸고 그 사진을 `images/`에 업로드하면 됩니다.

## 8. 스팸/중복 방지

- 봇 스팸 방지를 위한 허니팟(숨김 필드)이 기본 적용되어 있습니다.
- 동일 브라우저의 중복 제출을 막는 기능은 포함되어 있지 않습니다 (익명 설문 특성상
  이메일 인증 등 별도 장치 없이는 완벽히 막기 어렵습니다). 필요하시면 별도로 안내드릴 수 있습니다.
